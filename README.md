# rudder
Experimentation with Helm and GitHub Action

## Development

This is a TypeScript-based GitHub Action.

### Setup

```bash
npm install
```

### Build

```bash
npm run build
```

### Run

```bash
node dist/index.js
```

## Usage as GitHub Action

This action can be used in a workflow like:

```yaml
- uses: AndreasMoerch/rudder@main
```
